# Template — Positionnement premium (leçon Thorne)

## 1. Le client idéal (1 phrase)
> Notre client idéal est __________ qui a le problème __________ et paie volontiers pour __________.

## 2. La promesse (1 phrase, mesurable)
> Nous aidons __________ à passer de __________ à __________ en __________ (durée/chiffre).

## 3. Ce que vous refusez (aussi important que ce que vous vendez)
- [ ] Nous refusons les clients qui ne veulent que le prix le plus bas
- [ ] Nous refusons les projets sans objectif mesurable
- [ ] Nous refusons de travailler sans engagement clair

## 4. Le prix premium se défend par 3 preuves
1. Résultat chiffré (ex : +30 % de marge)
2. Témoignage spécifique (nom + chiffre)
3. Garantie forte (ex : 30 jours, remboursé si pas de résultat)

## 5. Le test des 5 secondes
Montrez votre page d'accueil à un inconnu 5 secondes. Il doit pouvoir dire :
« [ ] Je sais qui vous aidez  [ ] Je sais ce que vous promettez  [ ] Je sais combien ça coûte »
